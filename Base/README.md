# Base

A few files from Ladybird's `Base/` directory at the pin in `tests/libweb/PIN`, kept at the same
path relative to `tests/libweb` as Ladybird keeps them relative to `Tests/LibWeb`, because some
copied tests load them by relative path (`../../../../../Base/res/fonts/SerenitySans-Regular.ttf`).
Test data only; see `res/fonts/NOTICE` for the font's licence.
